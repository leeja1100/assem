8.10 Review Questions and Exercises
8.10.1 Short Answer 


1. 스택 매개변수와 지역 변수가 있는 프로시저의 에필로그에는 어떤 명령어들이 포함되는가?
답: mov esp, ebp, pop ebp, ret 명령어가 포함된다. ret에는 필요에 따라 매개변수 크기가 지정된다.

2. C 함수가 32비트 정수를 반환할 때 반환값은 어디에 저장되는가?
답: EAX 레지스터에 저장된다.

3. STDCALL 호출 규약을 사용하는 프로그램은 프로시저 호출 후 스택을 어떻게 정리하는가?
답: 호출된 프로시저가 RET n 명령어를 사용하여 스택의 매개변수를 제거한다.

4. LEA 명령어가 OFFSET 연산자보다 강력한 이유는 무엇인가?
답: LEA는 레지스터와 인덱스를 포함한 복잡한 주소 계산이 가능하지만, OFFSET은 정적으로 결정되는 주소만 구할 수 있기 때문이다.

5. 8.2.3절의 C++ 예제에서 int형 변수는 스택 공간을 얼마나 사용하는가?
답: 32비트 환경에서 일반적으로 4바이트를 사용한다.

6. C 호출 규약이 STDCALL 호출 규약보다 유리한 점은 무엇인가?
답: 호출자가 스택을 정리하므로 가변 개수의 매개변수를 전달할 수 있다.

7. 참/거짓: PROC 지시어를 사용할 때 모든 매개변수는 같은 줄에 나열해야 한다.
답: 거짓(False). 여러 줄에 나누어 선언할 수 있다.

8. 참/거짓: 바이트 배열의 주소를 워드 배열 포인터를 요구하는 프로시저에 전달하면 어셈블러가 오류를 발생시킨다.
답: 거짓(False). 주소의 대상 자료형이 다르더라도 어셈블러가 반드시 오류를 검출하는 것은 아니다.

9. 참/거짓: 참조 매개변수를 요구하는 프로시저에 즉시값을 전달하면 일반 보호 오류가 발생할 수 있다.
답: 참(True). 즉시값이 주소처럼 사용되어 잘못된 메모리에 접근할 수 있다.


8.10.2 Algorithm Workbench (알고리즘 실습)
1. STDCALL 호출 규약을 사용하는 AddThree 프로시저에 다음과 같이 세 개의 DWORD 값을 전달한다. EBP가 스택에 저장된 직후의 스택 프레임을 그려라.

push 10h
push 20h
push 30h
call AddThree

답:
높은 메모리 주소
[EBP+16]  00000010h
[EBP+12]  00000020h
[EBP+8]   00000030h
[EBP+4]   반환 주소
[EBP]     이전 EBP 값  ← EBP, ESP

낮은 메모리 주소

2. 세 개의 정수 매개변수를 전달받아 합계를 계산하고 EAX 레지스터에 반환하는 AddThree 프로시저를 작성하라.

답:
AddThree PROC,
    val1:DWORD,
    val2:DWORD,
    val3:DWORD

    mov eax, val1
    add eax, val2
    add eax, val3
    ret

AddThree ENDP


3. DWORD 배열을 가리키는 포인터인 지역 변수 ppArray를 선언하라.

답:
LOCAL ppArray:PTR DWORD


4. 20바이트 크기의 배열인 지역 변수 buffer를 선언하라.

답:
LOCAL buffer[20]:BYTE


5. 16비트 부호 없는 정수를 가리키는 포인터인 지역 변수 pwArray를 선언하라.

답:

6. 8비트 부호 있는 정수를 저장하는 지역 변수 myByte를 선언하라.

8. 전경색과 배경색을 스택 매개변수로 전달받아 Irvine32 라이브러리의 SetTextColor를 호출하는 SetColor 프로시저를 작성하라.

답:
SetColor PROC USES eax,
    forecolor:DWORD,
    backcolor:DWORD

    mov eax, backcolor
    shl eax, 4
    or eax, forecolor
    call SetTextColor
    ret

SetColor ENDP


9. 문자, 전경색, 배경색을 매개변수로 전달받아 지정된 색상으로 문자 하나를 출력하는 WriteColorChar 프로시저를 작성하라.

답:
WriteColorChar PROC USES eax,
    char:BYTE,
    forecolor:DWORD,
    backcolor:DWORD

    INVOKE SetColor, forecolor, backcolor
    mov al, char
    call WriteChar
    ret

WriteColorChar ENDP


10. Irvine32 라이브러리의 DumpMem을 감싸는 DumpMemory 프로시저를 작성하라. 선언된 매개변수와 USES 지시어를 사용하라.

답:
DumpMemory PROC USES esi ecx ebx,
    ptrArray:PTR BYTE,
    arrayLength:DWORD,
    arrayType:DWORD

    mov esi, ptrArray
    mov ecx, arrayLength
    mov ebx, arrayType
    call DumpMem
    ret

DumpMemory ENDP


11. 두 DWORD 배열의 포인터와 배열 원소 개수를 전달받는 MultArray 프로시저를 선언하고 PROTO 선언문도 작성하라.

답:
MultArray PROTO,
    ptr1:PTR DWORD,
    ptr2:PTR DWORD,
    count:DWORD

MultArray PROC,
    ptr1:PTR DWORD,
    ptr2:PTR DWORD,

MultArray ENDP
